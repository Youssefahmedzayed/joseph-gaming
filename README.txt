Joseph Games - موقع تحميل الألعاب
================================

تم إنشاء الموقع بنجاح.

الملفات الموجودة:
- index.html     → الصفحة الرئيسية
- admin.html     → لوحة التحكم
- styles.css     → التصميم
- script.js      → الوظائف

كيف تستخدم الموقع؟
------------------
1. افتح ملف index.html في المتصفح لتشوف الموقع.
2. لوحة التحكم: افتح admin.html
   كلمة المرور الافتراضية: joseph2026
3. من لوحة التحكم تقدر تضيف ألعابك (اسم + وصف + تصنيف + روابط ميديا فاير وتورنت).

ملاحظات مهمة:
- الموقع حالياً بيحفظ الألعاب في متصفحك فقط (localStorage).
- لو عايز الموقع يبقى دائم على الإنترنت:
  - ارفعه على أي استضافة مجانية (Netlify / Vercel / GitHub Pages / InfinityFree...)
  - أو اشتري استضافة ودومين.
- غيّر كلمة مرور لوحة التحكم من داخل ملف admin.html (ابحث عن joseph2026).

التصميم:
- داكن وحديث
- ألوان غامقة مع لمسات بنفسجي وسماوي
- أقسام: أجهزة ضعيفة / متوسطة / قوية
- أزرار ميديا فاير + تورنت
